# PaperBridge v0.1.0

PaperBridge lets you read an English DOCX beside its Chinese translation, edit Chinese text, review focused English changes and export a styled English DOCX copy with a replayable JSON change log.

## Highlights

- Word-rendered pages and a structural view for detailed diff and alignment work.
- Sentence correspondence colors, mouse-directed alignment and English word-first diffs.
- Provider-specific configuration and a new-version full retranslation workflow.
- A public [Attention Is All You Need demo](../../examples/attention/README.md) with real application screenshots, before/after text, DOCX files and JSON replay.

## Get started

This is a **source release**, not a standalone desktop installer. Tested primarily on Windows with Python 3.12 and Node.js 22. Word-native rendering also requires Microsoft Word; translation requires a configured local model service or API.

```powershell
.\setup.ps1
.\run.ps1 -OpenBrowser
```

Open <http://127.0.0.1:17865>, configure a model and import a DOCX. See the [README](../../README.md) and [user guide](../user-guide.md).

## Validation

Before publication: 73 backend tests, 4 frontend diff test groups and the frontend production build pass locally. Real local Qwen translation and rewrite examples were exercised; cloud providers were tested with simulated protocol responses. CI will repeat automated tests after the repository is pushed.

## Current limits

- DOCX only; output is a clean edited English DOCX plus JSON, not Word Track Changes.
- Native pages depend on Windows/Microsoft Word. Page anchors may fall back for ambiguous, repeated or protected content.
- Translation length changes may naturally alter line wrapping and pagination. Chinese preview does not guarantee semantic emphasis alignment across languages.
- Model outputs require human review for scientific meaning, numbers, terminology and citations.
