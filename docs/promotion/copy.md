## 小红书正文（可直接发布）

导师看完论文，说：「这句话，说得太满了。」

比如中文译文写着：

「我们的方法彻底解决了模型幻觉。」

如果真正想表达的是测试集上的观察，可以直接把中文正文改成：

「我们的方法在测试集上减少了模型幻觉。」

对应英文也可以从 “Our method eliminates hallucinations.” 回写为 “Our method reduces hallucinations on the test set.” 然后打开差异视图，自己核对英文增删和上下文，看看是否表达了想要的意思。

这组句子是原创功能演示，不是论文结论。哪些表述有证据支持，需要作者自己判断。

我把这样的修改流程做成了开源工具 PaperBridge：导入英文 Word，中英对照阅读；直接编辑中文译文；模型回写受影响的英文句子；检查 diff 后导出英文 Word 副本。图中的操作界面是真实截图，例句则用插画单独展示。

中英文的对应范围有时包含多句，所以回写也可能涉及多句英文。Word 原生版面需要 Windows 和 Microsoft Word；使用时还需配置本地模型或云端 API。术语、数字、引用和上下文仍需作者检查。

做过一次全文初译和句子映射测试，DeepSeek 映射约 0.12 元；这是单次样本，不含后续英文回写，火山初译费用取决于账号剩余额度。完整过程放在项目里。
