# PaperBridge：三渠道宣传内容与选图方案

设计版本：2026-11-04。社交平台图统一按 **1080 × 1920，9:16** 制作；GitHub 横幅另做横版。本文是制作方案，现有生成封面尚未全部转换为 9:16。

## 一句话定位

**改中文，同步改英文论文。**

导入英文 Word，中英对照阅读；直接修改中文译文，让模型回写对应英文，再看 diff、另存 Word。

读论文时少来回切换；改论文时用熟悉的语言写清意思；英文变化明确呈现，方便作者检查。不存在“中文意见框”、自动审稿或自动找出所有英文错误的功能。导入之前的 AI 改写历史也不会被自动还原。

## 已有截图怎么复用

已逐张查看三张截图，均为 1680 × 1080 横版。它们来自短篇 Attention 演示文稿，不能将截图上的“18/18 段”说成全文费用实验的进度。

- [attention-edit.png](../assets/attention-edit.png)：右侧编辑框约位于 x=1044–1540、y=650–868，须保留“原位编辑中文”标题与完整正文；用于图 03。坐标是原图取景参考，实际排版需保留边距。
- [attention-diff.png](../assets/attention-diff.png)：左侧 x≈280–900、y≈400–675，右侧 x≈1005–1615、y≈445–630 包含主要差异；分别等比例放大，在竖图中上下排列，标明左右来源，避免误导为实际竖版软件。
- 三张截图顶部右侧的导出控件可复用到图 05，但只能说明入口存在。若要展示导出后的真实 Word，应另补打开导出文件的截图。

不要把整个横版界面硬塞满一张竖图，手机上正文会太小。建议标题区约 15%、截图与局部放大约 65%、解释及脚注约 20%；外围留约 70–90 px 边距。统一米白、深蓝、青绿，红删绿增；用删除线和下划线同时表达差异。

封面原创幻觉例句与真实截图中的 Attention 措辞示例是两个不同例子，不能描述成同一次连续操作。现阶段分别标明“原创流程示意”“真实界面截图”；若后续拍连续视频，再在软件里录制同一例句的完整过程。

## 服务卡的准确文字

**专用翻译 API**：火山引擎机器翻译、DeepL API、Azure Translator、自托管 LibreTranslate。

**通用 LLM**：DeepSeek、OpenAI、Anthropic、Google Gemini、Kimi 开放平台；支持 LM Studio 本地服务及兼容协议的自定义接口。具体模型取决于账号可用性和结构化输出能力，不宣传“任意模型都可用”。

任务流程图：

1. 初始翻译：专用翻译 API **或** LLM。
2. 句子映射：选择 LLM；专用翻译生成的中英文固定后再建立对应。
3. 中文编辑后的英文回写：选择 LLM。

展示一套实际用过的组合：**火山初译＋DeepSeek 映射**；另列“可配置 LM Studio 本地模型”。不要把 ChatGPT／Claude／Kimi 网页会员等同于 API 授权，不写“所有服务免费”。平台名称使用文字即可，厂商标识不是本项目合作或认证标志。

## 费用卡的固定口径

主数字：**DeepSeek 消费约 ¥0.12，经使用者核对控制台。**

2026-11-04，以 Attention Is All You Need 的可编辑 Word 重建稿为样本。火山初译 27,490 字符；DeepSeek Flash 做句子映射，输入 91,124＋输出 7,858＝98,982 tokens。顺序执行约 5 分 51 秒。40 条参考文献及标题不翻译、不映射。

随图脚注：**单次实测；不含后续英文回写。火山费用视剩余免费额度。两段映射修复另计约 ¥0.0029。** 图像内部文字及脚注未翻译，译文需审校，详情链接[实测说明](../attention-cost-case.md)。

不要写“翻译一篇论文只要一毛二”“DeepSeek 全文翻译 ¥0.12”或“所有论文五分钟搞定”。

## 三条传播主线，各有一套选图

### A：中文修改，英文同步（首次介绍）

推荐顺序：01 → 02 → 03 → 04 → 05 → 08。先让人理解功能，服务与费用可放正文末尾。标题备选：

- 导师说“写得太满”？我直接改中文，再看英文怎么变
- 做了个开源工具：改中文，同步改英文论文

正文：

> 改论文时，有时中文已经想清楚该怎么改，落到英文里却还得来回核对。于是做了纸桥 PaperBridge：导入英文 Word，先对照中文阅读，直接修改中文译文，再让模型回写对应英文。打开 diff，就能检查哪些词句变了，确认后另存英文 Word。
>
> 比如封面的原创例子，把“彻底解决了模型幻觉”改成“在测试集上减少了模型幻觉”。这里是作者直接编辑中文正文，英文随之回写；真实软件画面见后几张图。
>
> 项目已开源。目前 Word 原生版面主要在 Windows＋Microsoft Word 上验证，需自行配置翻译／模型服务。欢迎带一篇合适的文稿试用，看看这个修改流程是否顺手。
>
> GitHub：github.com/jkjkiiiii/PaperBridge

### B：钱花在哪里（第二篇实测）

选图：07 做新封面 → 06 分工图 → 02 双语界面 → 04 差异截图 → 08 项目入口。标题：**火山负责初译，DeepSeek 负责映射，这次花了多少？**

正文：

> 拿 Attention Is All You Need 的 Word 重建稿跑了一次 PaperBridge：火山处理初译，DeepSeek Flash 给固定的中英文建立句子对应。DeepSeek 共消耗 98,982 tokens，控制台消费约 ¥0.12；40 条参考文献及标题自动跳过。
>
> 这个数字仅对应本次映射，不含后续中文编辑触发的英文回写。火山部分是否收费取决于剩余免费额度；两段后续映射修复另计约 ¥0.0029。完整数据与说明已放在 README。

### C：服务自己选（给已有 API 的用户）

选图：06 服务分工封面 → 03 中文编辑 → 04 diff → 08 上手入口。标题：**已有 DeepSeek 或本地模型，能接进论文编辑流程吗？**

正文：

> PaperBridge 可以分别配置初始翻译、句子映射和英文回写。初译可用火山、DeepL、Azure 或自托管 LibreTranslate，也可以选择通用 LLM；模型侧支持 DeepSeek、OpenAI、Anthropic、Gemini、Kimi 开放平台和 LM Studio 等。
>
> 配好后，日常操作还是直接修改中文译文、检查对应英文变化，再导出 Word。API 和模型由自己选择，相关请求按配置发送到所选服务。
