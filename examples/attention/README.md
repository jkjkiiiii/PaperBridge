# Attention Is All You Need · PaperBridge demo

This example demonstrates bilingual editing with a short quotation from **Attention Is All You Need**, two original paraphrases of its abstract, and an original editing sandbox and workflow table.

- **Paper:** Ashish Vaswani et al. (2017), [arXiv:1706.03762](https://arxiv.org/abs/1706.03762).
- **Input:** [attention-demo.docx](attention-demo.docx), generated by [build_attention_demo.py](../../scripts/build_attention_demo.py).
- **Scope:** the first 18-word abstract sentence is quoted. The next two paragraphs are adapted summaries, not quotations. This is not the full paper or an official Word version. The page design is created for PaperBridge and does not reproduce the original paper layout.
- **Attribution:** the excerpt remains attributable to the paper's authors. The source paper's rights are separate from this repository's code license; no full PDF, figures, or paper source is bundled.

## Reproduce

```bash
python scripts/build_attention_demo.py
```

Import the resulting DOCX, translate it using your configured model, then enable **结构编辑 → 差异视图** to review changes. Use **全部对应着色** to inspect bilingual sentence groups. **Word 原生版面** requires local Windows Microsoft Word.

## Suggested demonstration edits

1. In the adapted Transformer proposal paragraph, revise the Chinese wording for “relies entirely on attention” to a synonymous expression. Verify that the English rewrite touches only the corresponding sentence.
2. In the **Editing sandbox** paragraph, delete its middle sentence (“The original document remains unchanged.”) and insert a short sentence explaining that the change is for demonstration.
3. Export an edited DOCX and JSON change log, and compare the final text with the input.

These edits illustrate the software workflow. They are not scientific corrections, author revisions, or new claims about Transformer performance. Translation and back-translation still require human review.

## Included artifacts

| File | Purpose |
| --- | --- |
| `attention-demo.docx` | Original one-page demo input |
| `translation.json` | Initial translated state and sentence mappings |
| `changes.json` | Edited state, mappings and replayable change log |
| `attention-edited.docx` | Clean English DOCX exported by the application |
| `demo-edits.json` | Before/after texts for the two edited paragraphs |

For a model-free replay, import `attention-demo.docx`, then import `translation.json` to see the initial bilingual state. Import `changes.json` into the same project and enable the diff view to see the edits. Import previews should show no conflicts for the unmodified example. A model is required only when generating new translations or rewrites. Native page rendering still requires Word.

Screenshots in `docs/assets/attention-*.png` show actual application renders. The screenshot session lists only the public demo, so private working documents never appear in the gallery. Translation and rewrite outputs were generated with a local Qwen model; the edits are illustrative, not an evaluation of translation quality.
